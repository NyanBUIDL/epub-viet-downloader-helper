# Scrapling Helper cho Epub Việt Downloader

Bộ cài hỗ trợ chế độ Scrapling trên Windows 10/11 64-bit. Máy cần có Google Chrome.

## Tải bộ cài

**[Tải Scrapling Helper 0.12.0 cho Windows (.exe)](https://github.com/NyanBUIDL/epub-viet-downloader-helper/releases/download/v0.12.0-preview/Scrapling-Helper-Setup-0.12.0.exe)**

Đây là bản thử chưa ký số, tương thích với bản Chrome thử nghiệm của Epub Việt Downloader. Sau khi cài, mở tiện ích, chọn **Scrapling tích hợp** và bấm **Kiểm tra bộ hỗ trợ**.

[Xem bản phát hành và mã SHA-256](https://github.com/NyanBUIDL/epub-viet-downloader-helper/releases/tag/v0.12.0-preview)
